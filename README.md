# REM: THE LAST HUMAN WORLD

A 3D browser-based open-world survival game built with **Three.js**, **HTML5**, **CSS3**, and **JavaScript**.

## Features
- **Explorable Tokyo Park Environment** with procedural sakura trees, streetlights, and weather.
- **Dual Camera Mode** (Toggle between First-Person and Third-Person with `V`).
- **Oni Awakening Power** (`Q` key).
- **Survival Mechanics** (Health, Hunger, Thirst, Stamina, Time & Weather cycle).
- **Zombie AI System** responding to player proximity and movement.
- **Web Audio API** synthesizers for footsteps and ability cues.
- **LocalStorage Persistence** for saving and loading game progress.
